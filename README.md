# Data Analytics & Business Intelligence – Task 1

## Project Overview
This project focuses on data cleaning, exploratory data analysis (EDA), SQL-based analysis, and Power BI dashboard creation using a real-world sales dataset.

## Tools Used
- Microsoft Excel
- SQL Server (SSMS)
- Power BI Desktop

## Project Steps
1. Data Cleaning in Excel
2. Exploratory Data Analysis using Pivot Tables
3. SQL Analysis using SSMS
4. Power BI Dashboard Creation
5. Business Insight Reporting
